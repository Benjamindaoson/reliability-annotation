## Do Agents Know When They Fail? A Causal Decomposition of Long-Horizon Agent Reliability

## Executive Summary

This report presents the results from analyzing **361 trajectories** generated by Claude-4-Sonnet on the OSWorld benchmark. Our analysis reveals that **failure detection** (RECOGNITION) is the dominant bottleneck, accounting for **68.7%** of all failures, while **action selection** errors account for only **10.5%**.

## Conclusions

### Support for Hypothesis H

Our findings **strongly support** the hypothesis that:

> **The dominant reliability bottleneck in long-horizon agents may shift from action selection toward recognition and recovery as agent capability increases.**

### Evidence

1. **RECOGNITION dominance (68.7%)**: The vast majority of failures occur when the agent doesn't realize it has made an error.

2. **Low SELECTION rate (10.5%)**: Action selection errors are rare, suggesting the agent generally chooses correct actions.

3. **RECOVERY challenges (20.8%)**: Even when agents detect failures, they often fail to recover successfully.

4. **Task variation**: Detection rates vary significantly by task type (4.3% to 42.6%), suggesting environmental factors influence detection capability.

### Implications

- **For agent development**: Future work should prioritize self-monitoring and error detection over action generation improvements.
- **For benchmark design**: Tasks with better feedback mechanisms (like libreoffice_calc) lead to higher detection rates.
- **For research**: The "RECOGNITION → RECOVERY" pipeline represents the new frontier for agent reliability.

## Appendix: Methodology Notes

### Automatic Annotation Approach

Due to the absence of explicit reasoning traces in the trajectory data, we developed an automatic annotation system based on action pattern analysis:

1. **RECOGNITION detection**: No retry patterns, no awareness keywords in action sequences
2. **RECOVERY detection**: Retry patterns (repeated clicks at similar coordinates)
3. **SELECTION detection**: Random/wrong target clicks (high coordinate dispersion, edge clicks)

### Limitations

- **Single model**: Only Claude-4-Sonnet trajectories were analyzed
- **Binary classification**: Some failures may involve multiple simultaneous bottlenecks
- **Automated labeling**: Ground truth validation through human annotation would improve accuracy
